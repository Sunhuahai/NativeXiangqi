## Design decisions and conflicts

1. Signing evidence is never faked: without a Developer ID identity the gate
   records `developer-id: false` and the script exits nonzero; the report
   states the exact blocker instead of claiming a signed artifact.
2. Credentials stay out of the repository: notarization uses `NOTARY_PROFILE`
   or the `nativexiangqi-notary` keychain item; neither is committed.
3. The gate aggregates short deterministic checks (assets/source/policy/
   signing/lint/Swift+AppKit/rule label/identity) and records long-run
   measurements by reference rather than re-running the 30-minute benchmark
   inside `make release-gate`.
