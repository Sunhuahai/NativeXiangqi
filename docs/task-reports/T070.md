# T070 report

Status: accepted with an explicit review gate. T070 adds a versioned WXF-style
repetition-responsibility module (`wxf-2011-basic-v1`) with per-ply event
labels, cycle detection separated from responsibility classification, a typed
verdict (no action / draw / must-change / unsupported / ambiguous) with
deterministic explanations, a manually authored corpus, FFI batch exposure, a
native explanation panel with exportable note, profile persistence and undo /
branch compatibility. The UI badge stays "基础规则模式" until the corpus
passes independent human review (AGENTS.md gate; conflict recorded below).
Pikafish evaluation is never consulted.

## Summary

- Rules snapshot `wxf-2011-basic-v1` (profile id 2, version 1): the public
  repetition-responsibility subset documented in `docs/14-wxf-adjudication.md`
  with terminology mapping (将/捉/兑/闲/应将/须变着/和/不支持/存疑), provenance
  notes, and the explicit statement that full tournament adjudication is out of
  scope.
- Per-ply labels: `WxfPlyLabelV1` stored in variation nodes (check / chase with
  target, protection and trade evidence / exchange / idle / unsupported-reason).
  Classification is pure Rust over canonical events and positions; the only
  values are deterministic tenths-of-a-rook used for the exchange-vs-chase
  decision. No engine evaluation, no guessing.
- Cycle detection: position-hash occurrences on the active path (hash includes
  side to move); adjudication starts at `MIN_REPEAT_COUNT_FOR_ADJUDICATION` (3)
  occurrences; the cycle is the ply segment between the two most recent
  occurrences. Detection and classification are separate functions.
- Verdicts: uniform all-check/all-chase/all-idle cycles classify directly
  (长将须变着, 互将判和, 长捉须变着, 双方不变作和); every mixed pattern
  (一将一闲, 捉闲混合, 兑闲混合, 交替目标, 双方长捉, 多目标单着) is
  `Unsupported` or `Ambiguous` with a stable reason.
- Profile machinery: `RuleProfile::WxfV1`; `Game::set_profile` (root-only,
  transactional, re-seeds the repetition-hash chain with the profile
  id/version) plus `DocumentRestoreCandidate::set_profile` so reopened records
  are never silently reinterpreted. Profile id/version participate in
  repetition identity and cache keys (T060).
- Undo/branch: labels live in variation nodes; undo+redo restores the exact
  repetition hash and the identical adjudication result (tested).
- FFI (ABI minor 3 → 4, capability `ADJUDICATION`): `xq_game_get_adjudication`
  (bounded POD result + label batch + owned explanation buffer),
  `xq_game_set_profile`, `xq_document_restore_set_profile`.
- Swift: `XiangqiCoreGame.adjudication()`, `setProfile(id:version:)`,
  `XiangqiCoreAdjudication*` value types; document factories
  (`newWxfDocument`), profile-aware prepared-open/restore, profile-preserving
  FEN/UCCI replacement, `adjudicationText()` and a native explanation panel with
  a copy button in the analysis pane.
- Record codec: `ruleProfile.snapshot` distinguishes `base-v1` vs
  `wxf-2011-basic-v1`; both are round-trip preserved; unknown profiles fail
  closed.

## Design decisions and conflicts

1. Snapshot vs full rules: the corpus/implementation cover uniform cycles;
   mixed patterns are explicitly unsupported. This matches the quality bar and
   avoids heuristic adjudication. Full priority tables (将>捉>闲, 联合捉子,
   兑的细分) are documented as out of scope.
2. 互将 and 黑方长将 mirrors are covered as classifier-vector tests, not full
   legal-game fixtures: constructing verified legal perpetual mutual-check games
   requires reference patterns; the fixtures are marked pending independent
   review rather than shipping unverified positions.
3. Badge conflict: the task says remove the base-mode badge for the passing
   profile; AGENTS.md keeps "基础规则模式" until the WXF corpus passes
   independent review. Safest reversible resolution: the machinery is in place
   (profile-driven label), the badge stays, and the report records the conflict.
   Nothing claims full tournament adjudication.
4. Profile switch is root-only and re-seeds repetition identity, so a profile
   change is visible in every later hash/cache key; a non-root switch fails
   transactionally instead of silently reinterpreting.
5. ABI minor bumped for the three new functions and the ADJUDICATION capability;
   Swift rejects incompatible binaries as before (ABI checks unchanged).
6. `xq_game_set_profile`/`xq_document_restore_set_profile` use id/version
   pairs; unknown pairs are `INVALID_ARGUMENT`.

  象架捉无根马) → MustChange(Red); 双方长闲 → Draw; undo/redo preserves

  Unsupported; 兑对闲 → Unsupported; 黑方长将镜像 → MustChange(Black).
- In-crate unit tests: 多目标单着 → Unsupported(1); 有根同值目标 → Exchange.

  MustChange(Red), cycle, labels, explanation, buffer release).

  after moves rejected.
- Document: WxfV1 document persists profile and adjudicates after save/reopen
  (data round trip); base-v1 documents return nil adjudication.

   fixtures are pending review.
3. 兵/卒目标的捉、炮的特殊限制（无根炮等）、联合捉子、将捉闲完整优先级
   表不在快照内；这些局面返回 `Unsupported`。
4. The panel shows adjudication only for WxfV1 documents; base-v1 documents
   keep the existing behavior and badge.
